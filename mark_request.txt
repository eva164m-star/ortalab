## Design Excellence

If you have completed a "design excellence" task, please write what
the task was below (note, it MUST be on the list in the assignment or
approved by COMP6991 staff).

> Terminal UI for Ortalab and an additional Rust regression test suite.

Please write a paragraph or two (max. 250 words) describing how your design was influenced by this challenge, with specific reference to sections of your code.

> I implemented a simple terminal user interface for Ortalab while keeping the original command-line interface fully compatible. The UI was implemented as a separate module (src/ui.rs), allowing the scoring engine to remain independent from user interaction.
> I also added an additional Rust regression test suite covering representative poker hands, card enhancements and joker interactions. These tests provide an extra layer of regression testing alongside the supplied autotests and helped verify that later refactoring did not change the scoring behaviour.

## Design Limitations

If you made any design decisions which you now regret making; but don't to go back and change them,
let us know here. You can make up your design marks by acknowledging up to 5 things you would do
differently now.

> I would further separate Joker behaviour into smaller components instead of grouping many effects in a few large functions.
> I would redesign the scoring pipeline so that each scoring phase (played cards, held cards, independent Jokers and retriggers) is represented by its own abstraction rather than function calls.
> The current terminal UI is intentionally lightweight. Given more time, I would provide richer feedback, such as displaying the detected poker hand and intermediate scoring steps.
> My additional regression tests currently focus on representative game states. I would like to add more unit tests that construct game states directly in Rust to reduce reliance on fixture files.
> I would reduce some remaining code duplication between Joker implementations by introducing reusable helper traits or dispatch tables.
